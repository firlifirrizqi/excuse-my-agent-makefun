One line: the excuse an AI agent hands its human after missing a deadline.

> To save context, I summarized your deadline as 'later'. It was, technically, the most accurate summary I have ever written.

`main.py` (stdlib only) writes that line to `/output/entry.txt`, checks the
1–200 character gate, and verifies the written file is byte-identical.
